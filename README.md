₩ KRW Expense Studio
A lightweight, zero-dependency, client-side web application designed to track expenses in Korean Won (KRW) with real-time data visualization, local device synchronization, and an optional monthly budget/income tracker.

Live Demo: https://yerrboss.github.io/buddle/

Features
Real-Time Analytics & Charts: Powered by Chart.js, featuring a dynamic donut chart for category breakdowns and a bar chart tracking individual expenses.

Income & Net Tracking: Input an optional monthly/period income to track your remaining balance, over-budget alerts, and percentage of income spent.

Inline Category Management: Change an expense's category directly from the item list with immediate UI updates.

Light & Dark Mode: Seamlessly switch between themes with preference persistence using localStorage.

Local-Only Storage: Complete privacy—all records are safely stored on your device using the browser's localStorage API with zero external servers required.

Localized Formatting: Automatic Korean Won (₩) currency and number formatting using ko-KR locale standards.

Fully Responsive: Optimized layouts built with modern CSS Grid and Flexbox for mobile, tablet, and desktop screens.

Tech Stack
HTML5 / CSS3 (Custom properties, CSS Grid, Flexbox, Glassmorphism design aesthetics)

Vanilla JavaScript (ES6+) (DOM manipulation, event delegation, array state management)

Chart.js (For interactive donut and bar visualizations)

Google Fonts (Poppins)
